# Circuit Workbench

Circuit Workbench is being built as the thin, headless-backed operator inspection and review client of the circuit platform. It renders design views, run observations, acceptance reports, autonomy ceilings and canonical approval digests with their custodied evidence summaries — containing zero UI-only design, verification, learning or actuation logic. Its current executable surface is repository validation tooling. It has no installed workbench client, workspace-session service, review renderer or qualified record schema.

Read [Architecture](ARCHITECTURE.md), [validation tooling](validation-tooling.md), [data boundaries](THREAT_MODEL.md) and the [repository boundary decision](adr/0001-repository-boundary.md).
